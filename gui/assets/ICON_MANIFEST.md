
## 设计说明
- **设计主题**：粉白双色女仆剪影，与项目名「码铃」（MaLing）呼应
- **主色调**：玫粉色 (#EC5985) × 奶油白 (#FECEC9) 斜向撞色分割
- **构图**：画面由左上至右下的斜线分割为双色块，中央女仆剪影沿分割线左右撞色，与背景色块一一对应
- **设计元素**：女仆发箍蕾丝与围裙剪影、代码括号符号 `⟨⟩` / `{<>)` 点缀
- **启动画面**：splash_screen.png 与图标同套设计（1638×1024 高清源等比缩放至 800×500）
- **极小尺寸处理**：16×16 采用「正负形设计感」专用版（深玫红底 #c02067 × 白色对称正负形图形，三版候选中对比度最强的一版，用户三选一选定），保证小尺寸下轮廓清晰可辨


## 圆角规格（v10.13 起）

自 v10.13 起，本清单中全部应用图标与托盘图标（不含 splash_screen.png）统一改为**圆角正方形**：四个角以透明 alpha 通道裁切，主体图案不变。

| 尺寸 | 圆角半径 | 说明 |
|------|---------|------|
| 256×256 | 56px（约边长 22%） | PNG 与 maling.ico 内对应帧 |
| 128×128 | 28px（约边长 22%） | 同上 |
| 64×64 | 14px（约边长 22%） | 同上 |
| 48×48 | 11px（约边长 22%） | 仅 maling.ico 内帧 |
| 32×32 | 7px（约边长 22%） | PNG 与两个 ico 内帧 |
| 16×16 | 2px 微圆角 | 硬边处理（不抗锯齿），保证极小尺寸下轮廓清晰；仅角点像素透明 |

- 掩膜几何：圆角圆心位于四角向内 (r, r) 处，半径恰为 r；≥32px 尺寸采用 4x 超采样抗锯齿边缘。
- ICO 重建规则：目录项 w/h/colors/planes/bpp 字段与帧数量、帧顺序保持不变，仅帧图像数据带圆角（PNG 编码，32bpp）。
- 主体校验：不透明区域（alpha=255）的 RGB 像素与圆角前版本逐像素一致，改动仅发生在 alpha 通道。
