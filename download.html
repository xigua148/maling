码铃MaLing

叮铃一响、码上应答的女仆小铃铛——会聊天、会写码、有点小性格的桌面 AI 编程助手。

v1.0.0 · Windows
下载 码铃 v1.0.0（Windows） 备用下载（网盘镜像）

两个下载内容完全一致，哪个快用哪个。下载后解压，运行文件夹内的「MaLing.exe」即可，无需安装 Python。

首次运行弹蓝色提示怎么办？

  1. 首次运行时，Windows 可能弹出「Windows 已保护你的电脑」蓝色提示。这是因为码铃是独立开发者软件、未购买代码签名证书，Windows 会对所有这类软件统一显示该提醒，不代表检测到病毒。
  2. 在弹窗中点击「更多信息」；
  3. 点击「仍要运行」，码铃即可正常启动。
  4. 如仍不放心，可在运行前把压缩包上传到任意在线病毒扫描服务检查。

系统要求

  • Windows 10 及以上；
  • 无需安装 Python 与任何依赖（exe 已内置运行环境）。
