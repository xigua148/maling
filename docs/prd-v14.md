## 0. 一句话背景

v1.3.0 已完整交付：她听、她说、看得懂截图、随时找得到、有 4 款荷官小游戏。
v1.4 朝两个方向继续长大（用户拍板，并行）：
- **方向 A · 开源玩具盒**：借 MIT/Apache 开源件扩充「可玩内容 + 轻功能」，保持码铃「无焦虑、纯本地、MIT 可分发」的底座不被传染性许可污染。
- **方向 B · 看得见也能动手**：把「看图」升级为「看屏」，把「看屏」延展为「显式开启 + 逐次授权」的 GUI 操作（computer-use 轻量版）。

两条线各自独立、可并行立项；本 PRD 对每条线给出需求池 + 红线边界 + 待确认默认建议 + 裁剪建议。

## 1. 增量范围

### 1.1 方向 A · 开源内置（用户拍板：从网上开源项目找好玩/简单/可内置的小游戏与功能）
- A1 小游戏容器扩展：把 `gui/widgets/mini_games.py`（v1.3 P2-1，现有抛硬币/抽签/猜拳/21 点）扩展为可容纳「复杂交互型开源游戏」的容器。
- A2 首批开源小游戏内置（调研推荐 2 项：2048 + 扫雷，理由见 §6）。
- A3 轻功能容器与首批落地（调研推荐 1 项：番茄钟「她陪你专注」，呼应 v1.2 A10 专注陪伴观察项）。
- A4 开源许可合规与第三方归属（跨 A 线上位约束：THIRD_PARTY.md / 版权声明 / About 开源声明）。

### 1.2 方向 B · 屏幕理解 + GUI 操作（computer-use 轻量版，用户已拍板边界）
- B1 持续看屏模式（可开关；平时保留 v1.3 P1-2 手动截图问）。
- B2 GUI 操作（**逐次授权**：每次点击/输入前弹授权框；不做任务级自由操作）。
- B0 前置：需要视觉模型（README 已有 GLM-4V / qwen-vl / GPT-4o 配置指南；deepseek-v4-flash-vision-exp 类视觉模型可用时纳入厂商预设说明）。

### 1.3 明确不进 v1.4（此稿边界）
- **不做任务级自由操作**：码铃不得在一次授权后连续自主执行一串操作直至任务完成（用户拍板：逐次授权）。
- **不做自主周期采集**：无任何后台/空闲时自动截屏；看屏只在用户显式开启的持续模式内采集。
- **不做屏幕行为监督/使用报告**：不统计"今天看了多久网页/点了哪些应用"，不做时间线日志（与 R-B 同源，见 §5）。
- 节日限定皮肤/对话继续搁置；不做网络对战/云排行/账号。
- 剪贴板历史类被动采集功能（会静默记录用户复制内容）**不在方向 A 首批**（隐私边界见 §6 评估），如需另立专项评审。

## 2. 铁律红线区（v1.4 = v1.3 R-A~F 全量沿用 + R-G/R-H 新增）

> v1.3 R-A~F 全文沿用（prd-v13 §2）：R-A 无焦虑 / R-B 不监督不评判 / R-C 不做打扰式推送 / R-D 只增量不重构 / R-E 数据纯本地 / R-F 打包友好。v1.4 新增两条：

| # | 红线 | v1.4 强制口径 |
|---|---|---|
| R-A | **无焦虑红线延续（覆盖全部新游戏/新功能 UI）** | 心情/好感/token/进度/断签/倒数等养成数值零出现；**开源小游戏入内置前必须过「裁剪清单」**（见 §3 A4 与 §7 Q-A1：局内纯娱乐分值例外需团队拍板）；番茄钟不做成绩/统计/成就墙。红线扫描词表扩：`排行榜 / 最高分 / 连胜 / 连对 / 今日已完成 N 轮成就`。 |
| R-B | **不监督/不评判（延续 + 屏幕语义澄清）** | 摄像头/麦克风/在场感知仍永不做；**持续看屏分析的是"屏幕内容"而非"人"，且仅存在于用户显式开启时**；码铃不对用户屏幕行为做统计、不做"使用报告/时间线日志/自律监督"，只回答"当下这一帧有什么值得说/要不要我帮你点"。 |
| R-C | **不做打扰式推送（延续 + 看屏语境节流）** | 看屏主动提示只限"高价值事件"且节流（默认 ≤1 条/30 分钟、可关、仅对话气泡，无系统弹窗）；番茄到点提醒 = 用户主动启动的计时器完成通知，属用户预期动作（非打扰推送），但仅托盘静默气泡 + 可选语音，不做系统级弹窗。 |
| R-D | **只增量不重构（延续）** | 小游戏容器在 `mini_games.py` 基础上扩展（新增"游戏 widget 注册"机制），不推翻荷官四款既有实现；B 线新建 ScreenWatch/操作模块，不触碰 ChatService 用户发送链路（沿用 UI 直插唯一渲染入口）。 |
| R-E | **数据纯本地（延续）** | 看屏帧仅当轮内存、不落盘（用户主动"截一张"除外，走既有截图临时文件）；无屏幕时间线/历史记录文件；开源游戏无持久化排行数据。 |
| R-F | **打包友好（延续）** | 新增依赖逐个评估（§8 表）；操作模拟优先零依赖（ctypes SendInput），跨平台可选件单独标注体积/许可。 |
| R-G | **computer-use 轻量版边界（新增）** | ①操作 = 用户显式要求的单步动作，执行前**每次弹授权框**（不做会话级/任务级一次授权全放行）；②授权框展示「动作类型 + 目标坐标 + 该区域截图缩略预览 + 将输入文本（type 类）」，用户点「允许这一次 / 拒绝」；③**无自主周期采集、无后台自动操作、无跨会话记忆的屏幕内容**；④看屏仅在前台持续模式开启时采集，关闭立即停采并丢弃内存帧；⑤模拟键鼠仅作用于当前用户交互桌面，不做无障碍/UIA/进程注入/远程桌面操作。 |
| R-H | **开源许可合规（新增）** | 方向 A 内置源码**只收宽松许可**：MIT / Apache-2.0 / BSD-3 / 0BSD / CC0；**禁 GPL / AGPL / LGPL 传染链与 SSPL**（码铃整体 MIT 分发，静态内置违反传染性许可即整体被迫开源，不可接受）；PyQt 写的源码**只看源码仓库自身许可**（我们移植到 PySide6/LGPL 使用，PyQt 的 GPL 不传染我们的移植结果，但仓库若仅以 GPL 发布源码则仍不可用）；每个纳入项目必须保留原始版权声明（MIT 合规要求）并写入 `docs/THIRD_PARTY.md` + About 页「开源组件」。 |

## 4. 方向 B 需求池（屏幕理解 + GUI 操作，computer-use 轻量版）

| ID | 优先级 | 需求 | 说明（落点 · 边界/红线 · 依赖） |
|---|---|---|---|
| B0 | P0 | **视觉模型前提与降级** | 看屏/操作都依赖视觉模型。复用 v1.2.2 既有多模态发送链；当前 DeepSeek 官方纯文本不支持视觉，须在模型预设说明与开启引导中提示（已有 GLM-4V/qwen-vl/GPT-4o 配置指南；若 deepseek-v4-flash-vision-exp 可用则补进厂商预设并标注）。开启看屏时若当前模型非视觉 → 明确引导换模型，**不静默失败**。 |
| B1 | P0 | **持续看屏模式（可开关，她在看）** | **交互**：设置「视觉」区开关 + 聊天面板快捷开关（默认关）。开启：①显式确认弹窗：说明"码铃将周期性查看你的屏幕以提供帮助，消耗额外 token，可随时关闭"；②开启后聊天面板常驻「👀 码铃在看」状态 chip（醒目、可一键关）；③关闭即停采并丢弃内存帧。**采集策略**：默认 30s 间隔 + 屏幕内容显著变化立即触发（帧间 diff 轻量判定，Q-A4 默认）；提供「现在就看一下」按钮即时送一帧。**理解呈现**：①被动解释——看屏期间你直接提问（"这个报错为什么"）时基于最近帧作答；②主动提示——仅高价值事件（检测到报错/崩溃/异常对话框等）才开口，走对话气泡、节流 ≤1 条/30min、可关（Q-A5）。**成本护栏**：开启确认 + 看屏 chip 内显示"本会话已分析 N 帧 · 约 xxk tokens"（可折叠；类比首页 Token 卡累计口径，不逐条）；设置可设单会话帧上限自动暂停（Q-A6）。**落点**：新 `gui/screen_watch.py`（帧采集/ diff / 压缩 / 送视觉链）+ chip 状态条；复用 `screen_capture.py` 的屏抓函数（抽取，非对话框）。**红线**：R-B/R-C/R-E/R-G——绝无后台采集、无屏幕历史落盘、无行为统计。 |
| B2 | P1 | **GUI 单步操作（computer-use 轻量 · 逐次授权）** | **动作类型首版**：click（单击坐标）/ 双击 / 右键 / type 输入文字 / hotkey 快捷键（如 Ctrl+S）；scroll/拖拽 P2 观察。**触发链路**：普通聊天或看屏模式下对码铃说"点那个确定/把这个框填成 xxx"→ 码铃基于最近屏幕帧用视觉模型产出动作意图 `{type, target 描述, 坐标, 文本?}` → **执行前逐次授权弹窗**（增强版：动作 + 目标区域截图缩略 + 将输入文本明文预览；按钮 = 允许这一次 / 拒绝）；**无会话级放行**（R-G）；拒绝后码铃尊重结果不重试强推（沿用 agent 授权文案口径）。**执行后反馈**：执行成功即简短气泡"已帮你点了 (x,y) 的『确定』"；如模型不确定/识别置信低则先提问再动手（**宁可多问一次也不乱点**）。**落点**：新 `gui/computer_use.py`（意图解析 + 授权桥 + 执行器 + 结果反馈）；授权弹窗扩展现有 `agent_authorization_requested` 模式新起专用信号（带预览图参数），**不动 Agent 既有授权弹窗样式**。**模拟库**：默认 Windows ctypes `SendInput`（零依赖，R-F）；跨平台备选 pyautogui（BSD-3，+Pillow 体积，requirements 可选行）——架构裁决（Q-A8）。**安全**：type 输入前弹窗明文预览；对密码/密钥类输入模型意图若命中敏感语义额外红字警告，但**不做内容黑名单**（诚实提示优先，Q-A9）；不做任何键鼠记录/输入日志。**红线**：R-G 全条。 |
| B3 | P1 | **看屏驱动的统一底座（B1/B2 共享）** | 帧采集 / diff / 降采样压缩 / 坐标与 DPR 对齐（复用 screen_capture 多屏换算知识）收拢为 `ScreenWatchService`（app 级单例，B1 与 B2 同源消费最近帧），避免两套截屏代码。坐标对齐是点击准确性的关键（虚拟桌面负坐标 / 多屏 DPR 偏差，参照 v1.3 P1-2 已知边界并在此强化）。**红线**：R-G（帧仅内存、单例生命周期随看屏开关）。 |

## 5. 与既有红线映射 / 新增边界声明（防团队误读）

| 问法 | 澄清 |
|---|---|
| 「持续看屏是不是 v1.2『不做监督式陪伴』的倒退？」 | 不是。v1.2 红线针对的是**用摄像头/麦克风感知"人"**（在场/专注/内容分析）。看屏是**用户显式开启**、分析**屏幕内容**（且不做行为统计/时间线/使用报告，只答"当下这帧"），不感知人。边界已写 R-B。 |
| 「看屏会不会变成偷拍/后台常驻？」 | 不会。R-E + R-G：只在开启时采集、内存帧当轮即弃、关闭即停、无历史文件、主动提示节流。 |
| 「GUI 操作会不会变成让 AI 乱点你的电脑？」 | 用户已拍板**逐次授权**：每个动作执行前都必须弹窗允许，且允许仅针对该单次动作（R-G）。这是码铃产品里最重的授权粒度——比 Agent 工具的"会话级一次授权"更严，需在授权弹窗 UI 上明确体现"仅这一次"。 |
| 「开源游戏带分数是不是违反无焦虑红线？」 | v1.3 的四款荷官游戏是"结果型"，天然无分。v1.4 引入的 2048/俄罗斯方块等是"进程型"游戏，局内分/合成值是玩法核心。R-A 的禁止对象是**养成/焦虑**（心情/好感/经验/token/断签/排行攀比），本 PRD 判"局内纯娱乐分值 ≠ 养成数值"，但必须满足「不落盘、不排行、不成就、不连胜、不暴露累计」——此为产品判断，列入 Q-A1 待团队/用户确认。 |

## 9. 裁剪建议（分阶段，供排期参考）

1. **方向 A 必达（P0）= A0 容器 + A1(2048) + A2(扫雷)**：许可干净、改造量低、红线合规路径明确，一起交付形成"开源玩具盒"样板线。
2. **A3 番茄钟（P1）**：价值高但涉及会话/浮窗/TTS/托盘多落点，若与 B 线排期冲突可降 P2，不与 A10 观察项冲突（A10 本就延后）。
3. **A5 扩充池（贪吃蛇/数独/五子棋等）整体列 v1.4.x 或 P2**，自制优先于移植（无许可负担且与荷官文案整合更好）。
4. **方向 B 两段式**：B1（持续看屏·只读）为 v1.4 主承诺；B2（GUI 操作）为高风险高价值——**授权粒度、坐标准确度、真机 DPI 验证是三大风险**，建议 B2 首版动作类型仅 click + type，其余 hotkey/双击/右键/拖拽 P2。
5. **若资源收缩到只做一条线**：方向 B 的 B1 只读看屏 + 方向 A 的 2048/扫雷，是"两个方向都有代表性交付"的最优子集。

## 10. DoD 摘要（v1.4 完成标准）

1. **开源玩具盒立住**：2048 与扫雷可在「游戏角」内流畅游玩、随主题换肤、无任何养成数值残留（红线扫描词扩：排行榜/最高分/连胜/连对 零命中）。（A0/A1/A2）
2. **许可合规在案**：`docs/THIRD_PARTY.md` + About 开源声明 + 原版权行保留完整，无 GPL/LGPL 链混入。（A4）
3. **（若 A3 入选）她陪你专注**：番茄钟可用、不做成绩统计、到点提醒仅托盘气泡 + 可选 TTS、随 app 退出即停。（A3）
4. **持续看屏可用**：开启有确认与成本提示、chip 常驻可一键关、关闭即停采无残留；提问基于最近帧回答；主动提示高价值节流。（B1）
5. **单步操作可用**：click/type 经逐次授权弹窗执行成功，授权框含坐标预览 + 文本预览；拒绝即尊重；无会话级放行。（B2）
6. **红线归零**：R-A~H 全条对照验收；看屏关闭后内存帧丢弃（可自动化断言无缓存文件）；扫描词零残留。
7. **零回归 + 打包**：v1.3 能力（TTS/截图/热键/Idle/小游戏/免提/回忆/托盘/自启/纪念日/深色）无回归；`py_compile` 全绿；默认 exe 体积 0 新增依赖（ctypes 路径）。
