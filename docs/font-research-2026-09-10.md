## 1. 现状与需求拆解

- 现状：码铃 UI 现有 4 款系统字体 —— **幼圆 / 雅黑 / 楷体 / 等线**（均为 Windows 系统自带，随包分发时只能"借用系统字体"，非内置）。
- 幼圆（YouYuan）问题：系统自带、字形年代久、**仅 1 个字重**、圆角不统一，撑不起"精致可爱"的品牌气质。
- 需求：更圆润可爱、更精致的中文界面字体。
- 硬约束（本报告的核心筛选线）：码铃是 **PySide6 桌面应用、以 exe 随包分发给用户**，因此字体必须 **①授权允许嵌入 + 随包再分发**；②**简体中文常用字基本不缺**；③体积可接受（可子集化）。

## 3. 授权分级结论（决定"能不能随包"）

**A 级 —— 可自由嵌入并随软件分发（首选范围）**
所有 **OFL 1.1** 字体。OFL 明文允许"将字体安装于系统、软件或 APP 中""与任何软件捆绑再分发以及/或一并销售"，唯一红线是**禁止单独售卖字体文件**。包括：资源圆体、昭源环方、源泉圆体、有爱圆体、jf open 粉圆、猫啃忘形圆、寒蝉团圆体、得意黑、未来荧黑、霞鹜文楷、思源黑/宋、站酷（OFL 开源版）。
> OFL 义务：随包保留字体版权声明 + 附带 OFL 许可副本（放 `docs/third_party_licenses/` 或打包目录）。

**B 级 —— 可嵌入但附条件（谨慎）**
- **MiSans**：官方 FAQ 明确"可以嵌入式，但须在软件中特别注明使用了 MiSans 字体；不得改外观；不得再分发字体文件本身"。
- **HarmonyOS Sans**：免费商用、需开发者账号下载、不可修改。
- **OPPO Sans**：免费含商用，但不可改编、不得提供其他下载渠道。
- **阿里巴巴普惠体 3.0**：自有"永久免费商用"许可，嵌入条款需以官方许可原文再核。

**C 级 —— 嵌入/再分发存在冲突或不明确（不建议用于内置）**
- **阿里妈妈方圆体**：许可第 4 条列"不得……重新分发"与"嵌入式使用允许"并存，条款张力大，随包内置有争议风险 ⚠️。
- **致一圆体**：**IPA Font License 1.0**（非 OFL），有独立的衍生命名与再分发约束，须按 IPA 条款逐条核。
- **南西新圆体**：OFL 二创，理论上可嵌入，但 LICENSE 需以作者仓库原文确认。

**D 级 —— 禁止嵌入（排除）**
- 乐米系列（小奶泡体/元气团团体/惠圆体）：明确排除嵌入式用途。
- 阿里健康体 2.0：明确不含嵌入授权。
- 站酷**非开源版**（站酷快乐体/小薇的站酷发行版）：授权表标"软件嵌入式 ✗"。

## 4. 打包可行性（PySide6 内置字体方案）

### 4.1 技术路径
- `QFontDatabase.addApplicationFont(path)` 在运行时注册字体；返回 `fontId`，再用 `QFontDatabase.applicationFontFamilies(fontId)[0]` 取**真实 family name**（不能凭文件名猜）后设置给 QWidget/QSS。
- 打包：把字体文件放进 `_internal/fonts/`（与 Pi runtime 同级思路），用 spec `datas` 或收集脚本复制；运行期从 `sys._MEIPASS`/`_internal` 定位。
- 注意：**Qt 对 WOFF2 支持不可靠**，内置请用 **TTF/OTF**（不要把 WOFF2 当桌面内嵌格式）。

### 4.2 体积与子集化（关键）
全字库单字重 7–25 MB，直接内置多个字重会明显增肥。此时必须**子集化（pyftsubset）**：

- 工具：`pip install fonttools brotli`，命令 `pyftsubset 源.ttf --text-file=常用字.txt --output-file=子集.ttf`（可加 `--flavor=woff2`，但桌面内嵌建议保留 TTF）。
- 实测参照：思源宋体 **25.4 MB → 2.5 MB**（取 ~5000 字）；得意黑取 CJK 基本区 **1.8 MB → 896 KB**；再转 WOFF2 可再降约 30%（**仅供体积参考，桌面端不采用 WOFF2**）。
- **本报告估算**（按圆体字库轮廓复杂度）：
  - 单字重子集 **3500 常用字 + ASCII + 中文标点** ≈ **0.8–1.2 MB**；
  - 单字重子集 **6763 字（GB2312 全集）+ ASCII + 标点** ≈ **1.8–2.5 MB**；
  - 正文用 Regular + 强调用 Medium 两字重、6763 字子集 ≈ **总计 4–5 MB**。
- 相对码铃现状（Pi runtime 源码态约 206 MB、整包数百 MB），**4–5 MB 字体开销可忽略**，完全可接受。

### 4.3 风险与对策
- **动态文本超出子集**：用户输入、AI 回复可能含生僻字/emoji，落在子集外会显示为系统回退字形。**对策**：保留系统字体作为 fallback（QFont 家族链，如 `<圆体>, Microsoft YaHei, sans-serif`），Qt 会自动字形回退；子集取 6763 字已能覆盖绝大多数日常。
- **字体名归一**：子集化后 family name 可能被改（`--name-IDs`），建议显式保留原 family name 或在代码里读取 registry。
- **OFL 合规**：子集化属"修改"，须沿用 OFL、保留版权声明、附许可副本；保留名称（Reserved Font Name）规则需遵守（如资源圆体/昭源环方若有保留名，衍生子集不得冒用其名）。

## 5. 与现有 4 款系统字体（幼圆/雅黑/楷体/等线）的关系

建议 **「新增」而非「替换」**（保持用户选择自由度，符合码铃"陪伴优先、温柔"定位）：

| 现有字体 | 角色 | 与圆体的关系建议 |
|---|---|---|
| 幼圆 YouYuan | 系统可爱圆体 | **由内置圆体"接管"其角色**：把「资源圆体」作为新的默认可爱/正文圆体选项，幼圆降为可选回退（老用户习惯保留） |
| 雅黑 Microsoft YaHei | 系统高可读黑体 | **保留**，作为生僻字/子集外字符的 **fallback 保底** |
| 楷体 KaiTi | 系统文艺楷体 | **保留**，作"文艺/手写风"独立选项（可与霞鹜文楷并列，后者更精致且可随包） |
| 等线 DengXian | 系统现代黑体 | **保留**，作"极简/商务风"选项 |

**结论**：内置 1–2 款圆体（正文 Regular + 强调 Medium）+ 1 款可爱点缀（标题子集），其余系统字体保留作风格选项与 fallback。默认字体由幼圆切换为「资源圆体」，用户仍可在设置里切回幼圆。

## 6. 推荐结论详述

### 首选 · 正文/UI —— 资源圆体 Resource Han Rounded（OFL）
- 唯一同时满足「**圆体 + 简体一个不缺（GB2312/通用规范全）+ 7 字重 + OFL 可随包**」的组合，正文/UI/长文都稳。
- 保留黑体脚，圆而不失清晰，长时间阅读不累，比幼圆精致、比纯黑体柔和，契合"温柔陪伴"。
- 体积：单字重约 7 MB，子集化后 1.8–2.5 MB，两字重约 4–5 MB，代价可控。
- 缺点：程序自动变圆，个别笔画细节一般；字形偏"端正"，可爱度不如粉圆（但正文要的正是"耐看"）。

### 备选 · 更柔软精致 —— 昭源环方 Chiron GoRound TC（OFL）
- 现代笔形风格，圆角处理自然（非纯机械圆角），10 字重 + **可变字体 VF**（一个 VF 文件即覆盖全字重，能省掉多字重文件体积），西文内嵌 Nunito 混排协调。
- 若追求"更精致、字重层次更丰富"且接受更大体积（VF/单字重均偏大，建议子集化），可作正文或标题主字体。
- 缺点：单字重 24.7 MB 偏大，必须子集化；字形为港标现代风格，简体字形习惯上与大陆标准极接近但非完全一致。

### 标题/点缀 —— jf open 粉圆（子集）／寒蝉团圆体 Round（OFL）
- **jf open 粉圆**是全网最"Q 弹可爱"的开源丸体，最适合做 app 名/大标题/气泡标题；但其 **简体覆盖弱（GB2312 仅 69%）**，**不用于正文**；仅对少数标题字做子集，体积可压到几百 KB，同时规避简体缺字问题。
- **寒蝉团圆体 Round**：圆润亲和、仅 1 字重、3.9 MB，做副标题/点缀也很合适；同样 OFL 可随包。
- 二者二选一或按场景搭配；若只选一款，**粉圆的"可爱辨识度"最高**。

> 若最终只允许内置 1 款：选 **资源圆体**，安全、全面、可随包，最直接地解决"比幼圆更合适"。

## 8. 未能证实 / 存疑项（如实标注）
1. **精确体积缺口**：jf open 粉圆、未来荧黑、HarmonyOS Sans、MiSans、OPPO Sans 4.0、站酷小薇、南西新圆体、致一圆体 的**完整字库精确字节数未取得**（无权威公示值，不做猜测）。已取得精确值的均在 §2 列明。
2. **南西新圆体 LICENSE**：判断为 OFL 二创，但未直接读到作者仓库 LICENSE 原文，**建议核对**。
3. **致一圆体**：授权为 **IPA Font License 1.0**（非 OFL），可免费商用但衍生/分发条款与 OFL 不同，**须按 IPA 条款单独评估**。
4. **阿里妈妈方圆体**：官方许可同时出现"允许嵌入式使用"与"不得重新分发/二次修改"，**条款存在张力**，随包内置有争议，建议法律侧确认或不采用。
5. **阿里巴巴普惠体 3.0**：为自有免费商用许可，**嵌入条款未逐字确认**（§2 标注）。
6. **MiSans**：官方 FAQ 支持"可嵌入（须注明）"，但第三方授权表标注"嵌入式 ✗"，**存在口径差异**；以官方 FAQ 为准并保留署名义务。
7. **站酷字体双版本**：站酷发行版明确"不含嵌入授权"，而 Google Fonts 上的 **ZCOOL KuaiLe/KaiTi 为 OFL 版**可嵌入；若采用须确认取用的是 OFL 版。
8. **源泉圆体简体**：字表覆盖为满，但作者自述"简体容易出错别字"，**正文使用前需抽检**，故本报告仅将其列为备选/点缀而非正文首选。
